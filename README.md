# Celebrity-Face-Attributes-Analysis
**Exploratory Data Analysis | R | Data Visualization | Predictive Analysis | Facial Attribute Analysis**

## Project Overview
I analyzed the **CelebA facial attributes dataset** to explore whether facial characteristics, image dimensions, facial landmarks, and dataset partitions could be used to identify patterns associated with attractiveness.

The dataset contains **202,599 face images**, approximately **10,177 unique identities**, **40 binary facial attributes**, and **five facial landmark locations**.

## Research Questions
The project focused on four main questions:
-	What is the ratio of attractive people based on their facial attributes?
-	What is the ratio of attractive people based on image size?
-	How many attractive people are identified based on dataset partition?
-	What is the ratio of attractive people based on facial landmark information?

## Data Exploration
I examined several components of the dataset:
-	**Attribute data**
-	**Bounding-box / image-size data**
-	**Evaluation / partition data**
-	**Facial landmark data**

The analysis progressively narrowed the dataset and explored how different variables could be used to identify patterns related to attractiveness.

## Analysis Approach
I used R to:
1.	Read and examine the facial attribute data.
2.	Explore the available variables.
3.	Create visualizations of facial attributes.
4.	Analyze image dimensions and height.
5.	Examine dataset partitions.
6.	Analyze facial landmark locations.
7.	Develop predictive analyses using selected variables.
8.	Compare predicted results with the available test data.

## Predictive Analysis
The project also included predictive checks using different portions of the dataset.
The analysis reported:
-	**40%** correct predictions for the attribute-based analysis.
-	**40%** for the bounding-box analysis shown in the project.
-	**90.4%** correct predictions for the evaluation/partition analysis.
-	**40%** for the facial landmark analysis shown in the project.

## Key Takeaway
The analysis demonstrated that different types of facial data can be used to examine attractiveness-related patterns. The project explored four primary approaches—attributes, **bounding-box information, evaluation/partition information, and facial landmarks**—rather than relying on a single characteristic.

The project also demonstrated the process of moving from broad exploratory analysis toward more focused predictive analysis.
